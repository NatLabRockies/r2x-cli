title: Release history and versions
---

Read the canonical [changelog](https://github.com/NatLabRockies/r2x-cli/blob/main/CHANGELOG.md) and [GitHub releases](https://github.com/NatLabRockies/r2x-cli/releases).
These pages document the current `main` command surface.
Check `r2x --version` before comparing behavior.

For earlier documentation, choose the matching tag in [the repository tag browser](https://github.com/NatLabRockies/r2x-cli/tags), then open its `docs/` directory.
Tagged source documentation is available through GitHub; this site does not advertise separate historical builds.
The CLI is distributed as a binary; Python plugin package versions are independent of the CLI release.
